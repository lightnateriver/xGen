# H3 视频性能对比（20 步）

汇总 8 卡、768P 的当前推荐方案。5090 保留最新在线 Align16 数据；NPU 按提供的性能对照表，使用 **“910B2 截图／端到端耗时（秒）”** 列，不使用另一批 910B3 数值。

- **5090：Sage-FP8 全并行 Streaming＋BF16 AdaLN 表＋Align16**，SP8、文本 FP8 TP8、FP8 Linear／PHAA、50 层 DiT 常驻、native-stream。
- **NPU：VC attention＋INT8 全并行 Streaming**，配方按本轮提供的数据说明标注；设备名称沿用来源表的 **910B2**。

时间单位为秒。5090 显存为每卡 PyTorch 峰值 **allocated / reserved（GiB）**，取八 rank 最大值。NPU 来源没有配套显存数据，不套用 910B3 显存。

**NPU 来源**：提供的《xGen v0.5 昇腾性能对照》工作表“性能对照”，端到端取 `B2:B13`，去噪取 `C2:C13`。原表明确包含单图和五图参考，但未列图片像素 shape；表中图片尺寸仅描述 5090 输入。硬件标签按表头记录，本次未重新识别芯片或运行推理。

**计时口径**：5090 为服务端在线推理，包含条件编码、DiT、流式解码及重叠编码，不含 HTTP 排队、轮询和下载；20 次实际 DiT，完整匹配预热后正式测一次，初始化另计。NPU 保留来源表“端到端／去噪”名称，原表未附完整计时边界、预热和运行配置日志；不把“去噪”直接改称 DiT，也不从这些数值计算严格跨设备加速比。

**5090 来源选择**：在线数据采集于 2026-11-11～12。此次另附的离线报告前 9 项为 AdaLN owner、五图 3 项为缓存表，计时及 15 秒交付帧数也不同；按本次确认保留最新在线 Align16 列，不混换离线数字。

**验收范围**：5090 的 12 项正式请求及预热均技术通过，完整人工动态／口型／听音复核待记录。NPU 此列按提供的对照表完整回填，不将其他 910B3 批次的技术／人工验收结论转移到这 12 项。原工作簿的原版／合入版校验列不作为本列的人工质量结论。

本次只修正数据来源和设备标签，没有重新测量，也没有改动推理代码。
