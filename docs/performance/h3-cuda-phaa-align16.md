# GPU PHAA FP8 Align16 在线性能

采集日期为2026-11-11至12日。Sage-FP8全并行Streaming预设现默认包含Align16，T2VA/I2VA/R2VA共用这一组合。配置与独立关闭方式见[Align16指南](../H3-PHAA-FP8-ALIGNMENT.md)。

八卡RTX5090，每卡32GiB，SP8、文本FP8 TP8、PHAA2、50层DiT常驻、Sage attention、FP8 Linear与双向FP8通信、BF16 AdaLN表且对应权重不加载，native-stream解码。视频VAE采用FP16 autocast和Linear FP16存储，seed42。环境为PyTorch2.12、CUDA13、Triton3.7、Diffusers0.40、Transformers5.15、SageAttention2.2、NCCL2.29.7。

每项完整预热20次实际DiT，再正式20次，客户端串行提交。T2VA/I2VA共用一组常驻模型，R2VA单图和五图共用另一组，每组只初始化一次。初始化与预热单列，表内为正式请求。

历史对照与开启后使用相同prompt、图片、顺序、seed、表及输入shape。历史T2VA/I2VA、本轮T2VA/I2VA和本轮R2VA使用三个不同工作节点，历史R2VA与本轮T2VA/I2VA来自同一节点。因此以下全部为跨节点历史参考，耗时差异包含节点运行状态。不得将这些差异全部归因于Align16。

“推理”是服务端inference指标，包含条件编码、DiT和流式解码及其重叠编码。“HTTP”从提交至查询成功，包括受理、排队和轮询，不含后续文件下载、哈希及技术审计。“DiT”取八rank中实际20步device envelope累计时间的最大值。百分比按(历史−本轮)/历史计算，负值表示耗时增加。

## 验证范围

发布前针对默认绑定和CUDA设备入口追加回归，共166项通过、13个在线子测试通过。1项CUDA解码专项在CPU测试环境跳过，其中NPU默认/隔离由CPU配置契约测试覆盖。实际八卡成片数据来自下述在线矩阵，测量时显式开启Align16，发布预设自动选择同一配置。

12项正式与12次预热均通过视频/音轨完整解码、尺寸/帧数检查。192份rank快照核对20次实际DiT、模型及CPU master身份/加载次数、AdaLN表模式和权重缺席，以及实际通信计数。12个正式视频已在远端及下载后逐条验证SHA256。人工完整动态、口型及听音复核待完成。

另有同一工作节点、同一常驻模型的T2VA5秒A/B，在线推理41.590→32.187s，DiT33.330→25.145s。这组结果与上表的历史矩阵使用各自的对照值，详见[同机验证](../H3-PHAA-FP8-ALIGNMENT.md#验证结果)。
