# xGen SP4 与 TP2×CP2 单层性能（2026-11-06）

## 配置与口径

四张同节点 RTX 5090，固定为同一组卡。完整层宽：hidden=5376、FFN=14336、56 heads×128、time embedding=2688；仅一层，权重随机初始化 seed=42，不读取完整训练权重。三个方案都使用常驻 W8A8 FP8 Linear、Sage Q/K INT8 + PV FP8、双向 FP8 PHAA（2 chunks）、原有 indexed affine / QK RMS / partial RoPE 融合、world rank-owner AdaLN。

`sp4` 是原层级 SP4 路径，`tp2cp2-bf16` / `tp2cp2-fp8` 的后缀是 TP 通信精度；CP 一律 FP8。这里只计一个真实尺寸 DiT block，不包含输入编码、模型初始化、完整模型的本地 IO/输出 gather、VAE、RGB8、FFmpeg 或 HTTP E2E。

每个形状预热 3 次，正式 10 次；每次独立 barrier、GPU 同步在计时外，计时止于该 rank 的 GPU 完成。逐次取四 rank 最大 wall 时间，再取中位数；P90 使用 10 个样本的 nearest-rank。所有方案使用同一权重和输入。AdaLN 每次输入不同，保留原 exact cache，但不以固定 timestep 命中缓存人为提速。

同节点其他卡有业务，不是整机隔离。监控没有发现外部进程进入这四张测试卡；未主动锁频，结果代表本次同条件测试。

## 独立 profile（ms）

以下在正式计时后另跑 3 次，CUDA events 在相应计算/通信 stream 记录；每项先按 rank 平均，再取最慢 rank。模块包络包含其内部等待。CP 完整传输包含打包和解码，CP NCCL 是它的子区间；TP 数据归约包含打包/交换/FP32 求和（FP8）或原 all-reduce（BF16）。TP activation scale 是行 GEMM 的标量 MAX 交换。CP 通信可能与计算重叠，各列不可相加，也不能直接从 profile 推导正式总耗时。

|---:|---|---:|---:|---:|---:|---:|---:|
| 4,096 | sp4 | 3.10 | 1.09 | 2.20 | 1.88 | 0.00 | 0.00 |
| 4,096 | tp2cp2-bf16 | 4.00 | 1.87 | 1.90 | 1.54 | 2.03 | 0.24 |
| 4,096 | tp2cp2-fp8 | 18.02 | 18.51 | 2.06 | 1.73 | 29.46 | 2.14 |
| 16,384 | sp4 | 9.98 | 3.92 | 6.72 | 5.11 | 0.00 | 0.00 |
| 16,384 | tp2cp2-bf16 | 13.56 | 9.80 | 6.60 | 4.85 | 7.92 | 1.72 |
| 16,384 | tp2cp2-fp8 | 66.68 | 66.19 | 6.60 | 4.83 | 111.96 | 5.03 |
| 32,768 | sp4 | 24.07 | 6.64 | 18.00 | 10.01 | 0.00 | 0.00 |
| 32,768 | tp2cp2-bf16 | 31.95 | 14.61 | 17.83 | 9.52 | 15.64 | 0.18 |
| 32,768 | tp2cp2-fp8 | 137.96 | 115.95 | 17.77 | 9.53 | 222.77 | 0.51 |

32K 档的 BF16 TP 数据归约约 15.64 ms，而 CP 完整传输只由 18.00 ms 降到 17.83 ms；独立 profile 指向额外的两次 TP 行归约为主要延迟来源。

当前 FP8 TP 实现每块仅处理 262144 个元素。32K 全局 Token、CP2 下，每个行归约有 336 个 chunk，两次归约共 672 次 all-gather，并伴随逐块的打包、解码和 FP32 求和。其数据归约 profile 合计 222.77 ms，说明通信字节减少被小块 collectives 和算子调度开销抵消；不能把这条实现视为高性能 FP8 all-reduce。

单层峰值在 32K 档约为 SP4 2.36 GiB、TP2×CP2 2.35 GiB，几乎相同：只分摊一层权重，而 CP2 的局部 Token 数为 SP4 的两倍，激活及归约缓冲抵消了一部分权重收益。完整 50 层常驻时的静态权重收益和整体峰值仍需完整模型验证。

## 数值与资源边界

每个方案核对 64 个固定全局 Token 的 5376 维输出，TP 输出先去除重复，再还原全局位置，与同条件 SP4 比较。最大 sample relative RMSE 为 0.3421%。该检查用于排除切片/路由明显错误，不等于训练权重的视频精度通过。

原始每 rank JSON、10 次正式样本、profile、状态与逐 5 秒资源记录同目录保留。PyTorch 峰值不等于驱动全部显存。退出状态、外部进程检查和最终驱动显存保存在 status.json / monitor.jsonl。不能把单层耗时乘以 50 当作已测 E2E，也不能据此证明满载成片不会 OOM。
