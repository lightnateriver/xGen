# RTX5090 R2VA Sage-FP8 全并行：性能与验证

测试日期：2026-11-08至2026-11-09。8×RTX5090、SP8、1344×768、24fps、seed42、20次实际DiT。单图或五张原始2560×1440参考图，按固定顺序输入。

实测运行时：Python3.10.12、PyTorch2.12.0+cu130、CUDA13.0、Diffusers0.40.0、Transformers5.15.0、Triton3.7.0、SageAttention2.2.0。H3所需的原生模块与修补按原部署教程准备；版本号本身不能代替CUDA扩展编译和模型目录的检查。此表是实测环境，不要求NPU或其他CUDA模型安装这些版本。

每种形状先完整执行1步请求预热，再正式执行20步各一次。同一测试组内复用模型；五图10秒因原尝试设备异常在另一八卡组单独补齐，五图15秒也是独立测试组。所有正式结果均验证八rank实际步数、Sage内核调用、DiT50层全程常驻、请求内条件计算/复用/释放及直接stride打包。

计时是八rank中最大的生成并保存耗时，不含模型初始化、预热、技术检查和文件传输；不是HTTP客户端端到端延迟。每个场景只有一次正式样本，不代表p50/p99。旧Sage结果只引用已有历史数据，新旧节点不同，因此不能将差异全部归因于某一个算子。

## 方案包含的能力

FP8 W8A8主线性层、Sage Q/K INT8与P×V FP8、文本FP8 TP8、PHAA2双向FP8及直接stride打包、SAP本地FP32输出、本地输入投影、请求内固定条件预计算、Token Refiner SP8/cuDNN BF16/FP8 FFN、Qwen视觉SP8、VAE Encoder tile分工、Audio Encoder分工和长Audio Decoder分工。DiT50层在条件编码和VAE期间均常驻。保留原EXP、调制融合、FP16 VAE Decoder、VAE SP8/tile、RGB8与veryfast编码。TP/CP没有开启。

图片输入不会执行Audio Encoder，不能以这五项结果声称参考音频编码已经验证。单个测试成功也不意味着9图、音视频混合满载或所有CUDA设备都具有同样容量。

## 精度与异常边界

五条正式成片都完成视频/音频完整解码，每条12帧抽查未见黑帧或全幅噪声损坏；完整动态、口型与人工听音审核仍待完成。不得把技术通过写成全面人工精度通过。

五图10秒的原尝试在2/20步后发生CUDA launch failure，随后只有七张设备可枚举；没有捕获OOM，根因仍未确定。原尝试保留为失败，独立补测才构成该场景的技术通过，不删除原始故障记录。正式测试worker均已退出；补测组和15秒组的八卡显存归零，无计算进程。

优选推荐范围是已实测的离线R2VA768P、八卡5090。在线配置与功能入口已经补齐并做CPU回归，部署方接入业务前仍需用目标设备执行真实连续请求和下载解码。参考音视频并行、关闭单项后的CUDA成片以及9图/混合满载容量不在本表承诺范围内。测试结果不支持“长期无泄露”或全输入精度保证。

原Base服务退出需由外层启动器/容器监督并核对所有rank退出。本轮首次测试关闭父启动器后曾留下两个本测试rank，已按测试实例精确清理并保留证据；最终HTTP测试也由测试监督器确认八卡释放。不以父进程退出或HTTP请求完成推断所有worker已经释放，也不把该测试当成优雅停机能力验证。
