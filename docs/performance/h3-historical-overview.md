本页迁自原首页，保留历史 20／50 步、legacy decoder、NVFP4 等数据及其计时和验收说明。**这些不是当前推荐配置的统一对照结果。** 下文“最新”“本次”均指各条报告的采集批次；当前报告入口见[性能目录](README.md)。

## GPU 性能

八卡20步、全部 BF16 AdaLN 表模式的[在线 Align16 对照表](../performance/h3-cuda-phaa-align16.md)覆盖 T2VA/I2VA/单图及五图 R2VA 的5/10/15秒。每项完整预热一次、正式一次，初始化另计，逐项列出推理、DiT、HTTP耗时和峰值显存，并注明历史节点差异。

H3 VAE Decode 在 CUDA/NPU 均可选择 `--h3_vae_backend legacy|lightning|native-stream`。CUDA 推荐的 `fp8-bf16`、`fp8-sage` 和全并行预设默认 `native-stream`；NPU Base推荐脚本与在线预设默认 `native-stream`，其余低层离线入口保持既有选择逻辑，显式选择优先。H3 旧命令的 `--vae_lightning decoder` 需替换为 `--h3_vae_backend lightning`，其他模型的旧参数保留。实验性 [Native-stream 后端](../H3-OMNI-VAE.md)迁移原生 H3 tile 调度、分块输出、异步 D2H 和 MP4 编码，需要原生 `video_vae` 权重目录和显式授权。[组件实测对比](../performance/h3-omni-vae.md)包含性能、显存和精度验证范围。

昇腾也可选择 `native-stream`，需追加 `--vae_matmul_quant none`。已完成 [8×910B3 三后端组件对比](../performance/h3-vae-npu.md)：768P、5/10/15 秒，预热后新后端比 Lightning 快 1.57–1.95 倍；初始化单列，尚不代表整网加速或成片精度验收。

[默认切换验证](../performance/h3-vae-release.md)：134 项回归通过；八卡 5090 的新默认 R2VA 单图 5 秒链路连续两次 1-step 请求完成，第二次八 rank 最大调用耗时 11.48 秒，累计 allocated 峰值 29.14 GiB／卡。这里只验证链路与复用，不是完整步数的性能／精度结论。
