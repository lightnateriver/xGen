## 配置与计时口径

- B2，8 张昇腾卡，设备工具报告芯片名为 910B1，每卡物理 HBM 64 GiB。
- SP8，文本编码 TP8，PHAA2，Laser attention，Base DiT INT8，Base 实际执行 20 步；2K 另执行 3 步 BF16 Refiner。
- 768P 使用 INT8 Base VAE 与 decoder 优化，启用 NPU 解码前缓存清理。2K 使用 Refiner BF16 与分层权重加载。
- 每个用例先按相同配置预热一次，再正式计时一次。同组复用八卡进程与权重，模型初始化另列。
- 配置 A 为原矩阵。配置 B 为两项补测，启用上采样前缓存清理。B 使用的计算权重、seed 42 和 20+3 步与 A 一致。

“推理与保存”按现有推理入口计时，含视频生成及保存；“请求 wall”含请求处理和首条模型初始化。各阶段可能有重叠，阶段耗时不可直接相加替代端到端时间。

HBM 为每约 10 秒的驱动采样，可能漏掉短于采样间隔的尖峰。allocated/reserved 为请求排空后八 rank 的最大值。RSS 会重复计入共享页，进程树 PSS 更适合观察主机内存。
