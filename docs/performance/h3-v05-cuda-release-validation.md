# v0.5 CUDA 默认配置合并回归

日期：2026-11-11。基于远端 v0.5 `1883308` 合入 AdaLN 表与 FL2VA 配置后，使用该整理版源码实测；与[合并前的完整性能矩阵](h3-cuda-streaming-matrix.md)分开记录。

## 配置与结果

8×RTX 5090、SP8、文本 FP8 TP8、PHAA2、50层DiT常驻、768P、5秒、实际20步。低层 CLI 不传 precision／preset，通过默认解析选择 Sage-FP8 全并行、native-stream 和对应工作流的 BF16 AdaLN 表。仅显式提供任务、模型、卡数、步数及可信 native VAE 资产。

本轮是功能冒烟，**没有预热**，首个新算子／新形状的编译和首次触达包含在生成耗时里。E2E 是 Manager 的生成至保存耗时，模型初始化另列，不含 HTTP、下载或后验检查。首请求峰值可能包含模型初始化，不能用于与已预热矩阵直接推导性能变化。

| 用例 | 初始化 s | 生成至保存 s | 峰值 allocated GiB/卡 | 技术检查 |
|---|---:|---:|---:|---|
| T2VA 5s | 133.70 | 62.60 | 25.91 | 通过 |
| I2VA 5s | 0，复用前项模型 | 46.08 | 26.11 | 通过 |
| R2VA 单图 5s | 153.61 | 70.86 | 26.19 | 通过 |

三项各有八rank记录，均确认实际20次DiT、200个FP8主投影、350个FP8文本TP投影、对应AdaLN参数为0字节、DiT保持驻留、VAE CPU master身份稳定。FL2VA的两次请求仅构建模型一次，条件由无图切换到有图时按原缓存接口选表。

FL2VA使用完整条件表；Ref2VA使用已准备且通过指纹／步数校验的兼容BF16表。新格式及旧格式缓存加载分别有CPU契约测试。本次没有重新准备全部20／50步资产，没有重跑完整12项矩阵或做50步成片验收。

三条视频均为1344×768、124帧、24fps，带音轨；FFmpeg全片视频和音频解码、FFprobe与取回后的SHA-256校验通过。每条抽取0／2／4秒画面，未见黑屏或整体损坏；完整动态、身份、口型与人工听音仍待验收。

两组八卡worker均正常退出，核对无本批计算进程和设备占用后恢复原资源保留程序。此项说明生命周期清理有效，不是长期内存泄漏测试。
