# 昇腾 910B3：H3 VAE 后端性能对比

8×910B3、64 GiB/卡；1344×768；FP32 decoder 权重、FP16 autocast；不启用 INT8。模型常驻，各形状预热一次、正式一次，取八 rank 最大耗时。
同一组冻结 latent，计时从 latent H2D 到 MP4 完成，包含 VAE、RGB8 转换、D2H 和编码。初始化、DiT、Audio VAE、音频封装和技术验收不计入；本轮仅视频输出。
Legacy 为未开启 Lightning 的原 decoder 整段输出，使用既有 SaveAVStream 保存；Lightning 使用原八卡空间分块链路；Native-stream 使用原生全局 tile 分派、分块输出和异步 D2H。
Legacy 没有 decoder 并行，八 rank 执行同一输入，取最慢 rank；此处比较单请求延迟，不比较 DP 吞吐。

## 范围与证据

- 单图／五图仅表示冻结 latent 的来源；本轮不含参考图编码。内容和编码耗时存在差异，每形状仅一次正式测量，不能据此推断五图更快。
- Native-stream 初始化约 89.5 秒，旧两路约 5–6 秒；表中加速适用于预热后的常驻请求，冷启动需另计。
- 18 项正式输出分别进行分辨率、帧数、完整解码和 SHA-256 技术校验。模型参数对象和设备指针在各请求间保持稳定。
- 另完成两次单卡 256×256／13 帧暂存入口调用：H2D 0.568／0.571 秒，返回 CPU master 0.00454／0.00449 秒，权重对象稳定。该小尺寸验证不计入上表。
- 三组八卡 worker 均退出；暂存入口测试结束后八卡无计算进程。101 项 CPU 回归通过，2 项 CUDA 专用测试跳过。
- 性能张量来自已保存的首步推理，只用于组件对比，不作为成片视觉精度通过的依据。未重新生成 DiT 或检查音频。
- 不与 CUDA 表直接计算硬件加速比：本轮视频单流输出，CUDA 历史表含固定音频封装，Torch、硬件和依赖环境也不同。
- 910B1 仅完成小尺寸适配探针，未混入本表。全部正式结果来自 910B3。
- 此测试不代表 INT8 生产最优配置，不代表含 DiT 的整网延迟或容量，也不能凭单次形状矩阵证明长期无泄露。
