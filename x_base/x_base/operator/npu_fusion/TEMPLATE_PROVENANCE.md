# Kernel source provenance

The H3 Vector kernels retain the copyright and CANN Open Software License
Agreement Version 2.0 notices embedded in their source headers. They were
adapted from CANNBot Vector/add_custom templates and the installed CANN 9.1
RmsNorm/DynamicQuant reduction and casting sequence. The 2026-11-05 integration
relocates these sources without changing kernel or extension bytes. Native
framework integration, tensor lifetime protection and original numerical
rounding order are retained. Keep the installed CANN license terms with any
downstream redistribution of those adapted portions.
